# MonsterKillerGame

> Early 2022 JavaScript learning project — a turn-based monster combat game running in the browser.

## Overview
A simple browser-based combat game where the player battles a monster using normal attacks, strong attacks, and healing actions while tracking health bars and battle logs.

## Tech Stack
- **HTML5** & **CSS3**
- **Vanilla JavaScript** (DOM manipulation & game state logic)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/gorkemAlpaslan/MonsterKillerGame.git
   ```
2. Open `Monster-Killer Game/index.html` in your browser.
